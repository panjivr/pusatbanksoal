QR & Barcode Generator

Tempel link atau teks → langsung jadi QR code, Data Matrix, Aztec, PDF417, atau barcode EAN-13, UPC-A, Code 39, Code 128, ITF & Codabar. Atur warna, bentuk modul, bingkai, sampai logo di tengah. Unduh sebagai PNG, JPG, SVG, atau PDF, plus kode embed. Gratis, tanpa login.

Serba-guna: huruf, angka & simbol. Cocok untuk SKU, kode internal, tiket.

Pratinjau

🔒 Statis & privat. QR/barcode dibuat sepenuhnya di browsermu — isinya tertanam langsung di gambar, jadi tidak kedaluwarsa & tidak melewati server mana pun. Untuk QR dengan logo, gunakan koreksi error H agar tetap terbaca. Uji pindai sebelum dicetak besar.

Pertanyaan yang sering diajukan

Bagaimana cara membuat QR code dari link?

Tempel link/teks di kolom input — QR langsung muncul di pratinjau. Sesuaikan warna, bentuk, bingkai, atau tambah logo, lalu unduh (PNG/JPG/SVG/PDF) atau salin kode embed.

Apakah gratis dan tidak kedaluwarsa?

Ya. Ini QR statis — datanya tertanam di dalam pola QR, jadi berlaku selamanya, gratis, tanpa login, dan tidak bergantung pada layanan apa pun.

Format ekspor apa saja?

PNG & JPG (gambar), SVG (vektor, tajam di segala ukuran untuk desain/percetakan), dan PDF (siap cetak). Ada juga kode embed SVG, <img>, dan iframe.

Barcode apa saja yang didukung?

2D: QR Code, Data Matrix, Aztec (ringkas tanpa zona kosong — e-ticket kereta/pesawat) & PDF417 (bertumpuk, kapasitas besar — KTP & boarding pass). 1D (garis): EAN-13 & UPC-A (produk ritel), EAN-8 (kemasan kecil), Code 128 (huruf+angka serba-guna), Code 39 (industri/aset), ITF/Interleaved 2 of 5 (karton & logistik), dan Codabar (perpustakaan, bank darah, lab). Pilih jenisnya lewat menu Jenis barcode saat mode Barcode/Matrix.

Apa itu Data Matrix — "kotak sedikit tapi info banyak"?

Data Matrix (ECC200) adalah barcode 2D paling padat: dua digit disimpan dalam satu codeword dan ada koreksi error Reed-Solomon, jadi banyak data muat di kotak sangat kecil — dipakai untuk menandai komponen elektronik, alat medis, & obat. Cocok saat ruang cetak terbatas tapi butuh menyimpan serial/kode panjang. Dukungan sampai ~174 byte / 348 digit; untuk data lebih besar pakai QR.

Beda QR, Data Matrix, dan barcode 1D?

QR (2D) menyimpan banyak data termasuk link, dipindai kamera HP. Data Matrix (2D) paling ringkas untuk data pendek di ruang kecil. Barcode 1D/garis (EAN, UPC, Code 39/128, ITF, Codabar) untuk kode produk/SKU/aset, dipindai scanner laser toko & gudang.
