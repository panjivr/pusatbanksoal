Kirim Teks & File

Kirim teks dan file dari HP ke laptop, atau sebaliknya, dengan QR. Pilih cara yang kamu butuhkan di bawah. Gratis dan tidak perlu login.

Hubungkan dua perangkat

Pilih peran perangkat ini. Satu menampilkan QR, satunya memindai, setelah terhubung, keduanya bisa saling kirim teks & file.

Butuh internet di kedua perangkat (tak harus satu Wi-Fi). File dikirim langsung antar perangkat, tidak lewat server.

Kecepatan putar QR (teks panjang)

Pindai QR dari perangkat lain

🔒 Privat & aman. Semua transfer terenkripsi dan kunci pembukanya hanya ada di QR, tak pernah dikirim ke jaringan. Mode Kirim teks dan file mengirim file langsung antar perangkat (P2P); hanya sinyal sambungan yang lewat perantara, dalam keadaan terenkripsi. Mode Kirim teks tanpa internet bekerja tanpa internet sama sekali. Kamera butuh izin & HTTPS (otomatis di situs ini).

Pertanyaan yang sering diajukan

Berapa ukuran file maksimal?

Mode Kirim teks dan file mengirim file langsung antar perangkat (P2P), jadi tak ada batas server, nyaman sampai sekitar 100 MB (tergantung memori perangkat & kecepatan jaringan). File besar butuh sedikit waktu; biarkan kedua layar tetap menyala.

Apakah file/teks saya lewat server?

Tidak. Di mode Hubungkan, file mengalir langsung antar perangkat (WebRTC, terenkripsi). Hanya sinyal sambungan kecil yang lewat relay publik, itu pun terenkripsi. Mode Teks kilat tanpa internet sama sekali.

Komputer saya tidak punya kamera, bisa?

Bisa. Di komputer pilih Tampilkan QR, lalu di HP pilih Pindai untuk menyambung. Setelah terhubung, kirim file/teks dua arah, HP ke PC maupun sebaliknya.

Perlu aplikasi atau satu Wi-Fi?

Tak perlu aplikasi. Mode Teks kilat tak perlu internet. Mode Hubungkan perlu internet di kedua perangkat (tak harus Wi-Fi sama); paling lancar bila keduanya satu Wi-Fi.

Kenapa gagal menyambung saat mengirim file?

Sebagian jaringan kantor/seluler membatasi koneksi langsung antar perangkat. Coba lewat hotspot HP atau Wi-Fi rumah. Untuk teks yang pasti jalan, pakai Kirim teks tanpa internet.

Tentang Kirim Teks dan File

Kirim teks dan file antara HP, tablet, dan laptop melalui QR. Pilih koneksi antar perangkat untuk file atau kirim teks tanpa internet. Tidak perlu memasang aplikasi atau login.
