# Bekal web adaptation

Based on AI Video Production Editor by Ludwig Maximillian Kienle, upstream commit `752cd43d3af6421d2bd6d4ce27f2d9815f7acba3`. This modified editor retains GPL-3.0-or-later; see LICENSE and NOTICE. The fork is named Studio Film AI Bekal and does not claim upstream endorsement.

Changes: integrated static Vite entry, browser-only local session, IndexedDB project/media persistence and backup restore, Bekal theme tokens, Indonesian main navigation, direct provider credential requests, lazy-loaded workspaces, locally compiled Tailwind, and existing-site catalog/Pages integration. Original optional Electron/cloud/provider source remains available.

Web build instructions and required shared build scripts are in the parent repository's docs/FILM-STUDIO.md and scripts/sync-film-theme.py / scripts/publish-film-studio.py. Source is publicly available in https://github.com/panjivr/pusatbanksoal/tree/claude/minimal-token-web-build-5b228s/studio-film-ai . This is a web adaptation; upstream desktop build instructions may require additional prerequisites.
