Pilih alat untuk mulai

Atau tarik file ke sini. Maksimal 20 file, 50 MB per file, total 100 MB.

    Pengaturan

    Periksa pengaturan dan hasil sebelum membagikan file.

    Hasil siap diunduh

    File tetap di perangkatmu

    Pilih alat, tambahkan file, lalu atur hasil yang kamu inginkan. Kamu bisa memproses beberapa file sekaligus dan mengunduh hasil satu per satu atau dalam ZIP. File dan password tidak disimpan sebagai riwayat.

    Mengapa hasil konversi bisa berbeda?

    Font, tata letak, dan kualitas scan dapat memengaruhi hasil. Baca keterangan alat dan periksa file hasil sebelum digunakan. Konversi Office memiliki batas yang dijelaskan pada masing-masing alat.

    Apakah bisa dipakai di HP dan tablet?

    Bisa melalui browser modern. Mulai dari file kecil untuk menghemat memori. OCR dan pemrosesan banyak halaman membutuhkan waktu lebih lama; biarkan halaman terbuka sampai selesai.
