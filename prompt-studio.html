Prompt Studio

Rakit prompt banner, tinggal salin-tempel

Pilih platform, gaya, warna, dan teks — studio menyusun prompt yang sudah diformat sesuai tool AI pilihanmu (Midjourney, DALL·E, Stable Diffusion, Ideogram). Outputnya satu: prompt siap tempel. Semua diproses di browser, tanpa akun.

Unggah untuk pratinjau & panduanmu. Midjourney: tempel URL gambar (jadi --sref/--cref). DALL·E/ChatGPT: lampirkan gambarnya langsung di tool. Gambar tidak diunggah ke server mana pun.

        Tips agar hasilnya bagus
        
    
          
  • Prompt dalam bahasa Inggris umumnya memberi hasil paling akurat pada model gambar.
    • 
          
  • Teks pada gambar sering meleset di sebagian model — untuk banner ber-teks, pakai Ideogram atau DALL·E 3, dan buat headline singkat.
    • 
          
  • Iterasi: hasilkan beberapa variasi, lalu perhalus warna/komposisi lewat catatan tambahan.
    • 
          
  • Sisakan ruang kosong bila kamu akan menambah teks/logo sendiri setelahnya.
