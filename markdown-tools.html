Alat Markdown Gratis

Tulis catatan, konversi dokumen, dan susun ringkasan video dalam format .md. Baca pratinjau sambil mengedit, lalu unduh hasil beserta asetnya.

Dokumen diproses di perangkatmu. Transkripsi otomatis mengunduh model suara saat pertama digunakan; audio tidak dikirim untuk diproses di server.

RUANG KERJA

Editor Markdown

Buka dokumen atau langsung tulis di editor.

Tidak ada batas ukuran file buatan. Dokumen diproses sesuai kemampuan perangkat. Pratinjau dokumen besar menampilkan bagian awal; unduhan tetap utuh. Isi editor tidak disimpan otomatis. Unduh dokumen sebelum menutup halaman.

PDF ke Markdown dengan sumber lengkap

Markdown tidak dapat menyimpan semua komponen dan tata letak PDF. Paket ZIP menyertakan PDF asli tanpa perubahan, gambar halaman, teks, tautan, dan data ekstraksi agar sumbernya tetap tersedia.

Ringkasan video dan audio

Gunakan transkrip yang sudah ada atau transkripsikan suara di perangkatmu. Model Whisper Tiny perlu unduhan awal sekitar 100 MB, membutuhkan memori besar, dan bisa lambat pada HP. Periksa ejaan, nama, dan angka. Ringkasan memilih kalimat dari transkrip.

Tautan video YouTube atau layanan lain tidak diunduh. Gunakan file media yang kamu miliki. Suara membutuhkan codec yang didukung browser.

      Alamat eksternal tidak diperiksa lewat jaringan. Pemeriksaan ini tidak menilai kebenaran isi.
      Simpan hasil
      Pilih ZIP jika dokumen memakai gambar lokal. DOCX mempertahankan struktur umum; ekstensi dan tata letak kompleks bisa berbeda. Unduh Markdown asli sebagai rujukan.
      Hasil konversi PDF disimpan di browser perangkat ini agar dapat dipulihkan setelah halaman dimuat ulang.
      Panduan Markdown
      Markdown adalah teks biasa dengan penanda struktur. File .md mudah dipindahkan, dibaca oleh manusia, dan disimpan sebagai dokumentasi. Dukungan tampilan berbeda antar aplikasi.
      Sintaks dasar dan Markdown GitHub
      Gunakan # untuk heading, **tebal**, *miring*, tanda - untuk daftar, [nama](alamat) untuk tautan, dan tiga backtick untuk blok kode. Alat ini mendukung tabel, daftar tugas, coretan, dan tautan otomatis bergaya GitHub. Raw HTML disaring untuk pratinjau aman.
      Front matter, gambar, dan ekstensi
      Metadata YAML di antara dua baris --- ditampilkan terpisah dan tetap disimpan pada file MD. Tambahkan gambar lokal atau buka paket ZIP agar gambar tersedia. Rumus LaTeX, diagram Mermaid, dan ekstensi aplikasi tertentu tetap dipertahankan sebagai teks atau blok kode; tidak semua ekstensi dirender.
      Apakah PDF bisa diubah ke Markdown tanpa kehilangan informasi?
      Struktur PDF sering tidak memiliki informasi heading, tabel, atau urutan baca. Alat ini menyimpan PDF sumber utuh dalam paket, disertai tampilan setiap halaman, teks, dan informasi ekstraksi. Baca gambar halaman untuk tata letak aslinya. PDF hasil scan dapat menggunakan OCR, yang perlu diperiksa kembali.
      Bagaimana ringkasan video dibuat?
      Suara ditranskripsikan dengan model yang berjalan di browser, atau kamu dapat memakai transkrip SRT/VTT/TXT. Ringkasan memilih kalimat penting dan menyertakan transkrip lengkap. Ini bukan penafsiran otomatis semua objek visual dalam video. Cuplikan bertimestamp membantu memeriksa bagian visual.
      Apakah ada biaya atau unggahan dokumen?
      Tidak ada layanan pemrosesan berbayar. Dokumen dan audio tetap diproses di perangkatmu. Unduhan model transkripsi menggunakan koneksi internet dan dapat disimpan dalam cache browser untuk pemakaian berikutnya. Akurasi serta kecepatan bergantung pada suara dan kemampuan perangkat.
